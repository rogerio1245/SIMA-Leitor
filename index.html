1. Fotografar o cartão

Use exclusivamente o cartão SIMA Fundamental I padronizado com quatro quadrados pretos separados. Fotografe a folha inteira, sem cortar marcadores, com boa iluminação. A câmera nativa é usada sem transmissão de vídeo contínuo.

Carregando biblioteca OpenCV.js. Na primeira abertura, é necessário acesso à internet.
Aguardando fotografia.

2. Localização dos quatro marcadores

Primeiro tente Detectar automaticamente. Confira os quatro pontos verdes sobre os centros dos quadrados pretos. Se falhar, use Marcar manualmente e toque nos centros nesta ordem: superior esquerdo → superior direito → inferior direito → inferior esquerdo. Toque novamente em “Marcar manualmente” para reiniciar os quatro pontos.

Aguardando localização.

3. Conferência da leitura

A imagem abaixo foi retificada conforme os quatro marcadores. Os anéis coloridos representam as regiões medidas. Verde: marcação provável; laranja: conferir; cinza: não foi possível identificar. Uma marcação detectada não é confirmação de acerto da resposta.

Informações técnicas

O reconhecimento utiliza OpenCV.js para localizar quadrados e corrigir a perspectiva, e compara as regiões internas dos círculos com uma imagem vetorial renderizada do cartão em branco. Não usa OCR das letras. A biblioteca OpenCV.js é carregada pela internet (CDN); depois de carregada, as fotografias são analisadas localmente. Esta é uma versão experimental, não validada para lançamento de notas. Use cartões com respostas conhecidas para medir erros antes de utilizar em avaliações reais.
